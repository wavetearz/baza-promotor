# Strona główna
Interfejs strony głównej składa się z tabeli wynikowej oaz panelu do wyszukiwania.

## Panel Główny

### Wyszukiwanie promotorów

W panelu głównym użytkownik może wyszukiwać sekwencje promotorów poprzez pole tekstowe oraz stosować filtry:

- **Pole wyszukiwania** – pozwala wyszukać promotor po fragmencie nazwy genu lub sekwencji.
- **Filtry**:
  - Typ organizmu
  - Funkcja genu
  - Typ danych

### Paginacja

- Przyciski **Poprzednia / Następna** umożliwiają przechodzenie między stronami wyników.
